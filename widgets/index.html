Widgets

Add a widget in one click.

Ready-made widgets use the sources built into Glyx with settings filled in. Widget sources are new kinds of widgets, each a small sandboxed plugin you can read before installing.

  1. Add to GlyxPick the page; the widget lands in its emptiest column.
  2. Install a sourceGlyx lists what the source may access before you agree.
  3. Or downloadDrop the .json or .zip file on the Glyx window.

Ready-made widgets

Built-in widgets with useful settings. Change anything later in the widget's settings.

Widget sources

New kinds of widgets, installed into Glyx Full. Each runs in its own sandbox with only the access it lists.

Build your own widgetA widget source is a folder with manifest.json, index.html and a script. Send a pull request to list it here.
